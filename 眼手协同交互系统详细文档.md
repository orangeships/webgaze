## 1. 项目概述

### 1.1 系统定位
眼手协同交互系统是一个基于眼动追踪技术的智能人机交互解决方案，旨在提供更自然、直观的交互体验。系统通过高精度眼动追踪，实现视线控制鼠标的新一代交互模式。

### 1.2 核心功能
- **高精度眼动追踪**：实时捕获用户视线位置
- **智能鼠标控制**：视线驱动的鼠标自动移动
- **多显示器支持**：原生支持多屏幕环境下的无缝切换
- **自适应校准**：多种校准模式适应不同精度需求
- **视觉反馈系统**：直观显示注视点和操作状态

### 1.3 应用场景
- **无障碍辅助**：为行动不便用户提供便捷操作
- **VR/AR应用**：沉浸式交互体验
- **多显示器办公**：提高工作效率
- **游戏娱乐**：增强游戏沉浸感
- **工业控制**：远程操作和精密控制

## 4. 核心校准参数

### 4.1 STransG变换矩阵

#### 4.1.1 定义与作用
STransG（Screen Transform Gaze）是核心的4×4齐次变换矩阵，负责将相机坐标系中的视线向量映射到屏幕坐标系统。

```
STransG = [R  t]
          [0  1]
```
其中：
- R：3×3旋转矩阵
- t：3×1平移向量
- 第四行：[0, 0, 0, 1]（齐次坐标）

#### 4.1.2 计算过程
```python
def compute_STransG(camera_points, screen_points):
    """计算STransG变换矩阵"""
    # 1. 构建齐次坐标
    camera_homogeneous = np.hstack([camera_points, np.ones((9, 1))])
    
    # 2. 直接线性变换求解
    A = []
    for i in range(9):
        x, y, z = camera_homogeneous[i]
        u, v = screen_points[i]
        A.append([x, y, z, 1, 0, 0, 0, 0, -u*x, -u*y, -u*z, -u])
        A.append([0, 0, 0, 0, x, y, z, 1, -v*x, -v*y, -v*z, -v])
    
    A = np.array(A)
    b = np.array([u, v] * 9)
    
    # 3. 最小二乘求解
    params = np.linalg.lstsq(A, b, rcond=None)[0]
    
    # 4. 重构4×4矩阵
    STransG = np.zeros((4, 4))
    STransG[0, :4] = params[:4]
    STransG[1, :4] = params[4:8]
    STransG[2, :4] = params[8:12]
    STransG[3, 3] = 1
    
    return STransG
```

### 4.2 STransW矩阵

#### 4.2.1 结构组成
STransW是4×4齐次变换矩阵，由以下分量组成：
- **SRotW**：3×3旋转分量，表示世界坐标系相对于参考坐标系的旋转
- **StW**：3×1平移分量，表示世界坐标系相对于参考坐标系的平移

```
STransW = [SRotW  StW]
          [  0     1 ]
```

#### 4.2.2 作用机制
- **桥梁作用**：连接SfM世界坐标系与屏幕坐标系
- **中间变换**：STransG = STransW @ WTransG * scaleWtG
- **参数复用**：避免重复计算相同的变换关系

### 4.3 scaleWtG缩放因子

#### 4.3.1 物理意义
scaleWtG是一个标量缩放因子，用于调整从SfM世界坐标系到屏幕坐标系的距离尺度。

#### 4.3.2 优化过程
```python
def optimize_scale_wtg(stansw, wtransg, measured_points):
    """优化scaleWtG缩放因子"""
    def scale_error(scale):
        # 构建变换矩阵
        STransG_scaled = stansw @ wtransg * scale
        
        # 计算投影误差
        projected = transform_points(measured_points, STransG_scaled)
        return np.linalg.norm(projected - measured_points)
    
    # 使用scipy优化器
    from scipy.optimize import minimize_scalar
    result = minimize_scalar(scale_error, bounds=(0.5, 2.0), method='bounded')
    
    return result.x
```

## 5. SfM模式数学原理

### 5.1 传统方法的局限性

#### 5.1.1 参数冗余
传统直接优化16个参数的4×4矩阵存在以下问题：
- **自由度冗余**：4×4矩阵只有12个独立自由度
- **数值不稳定**：16参数同时优化容易陷入局部最优
- **计算复杂度高**：高维参数空间增加优化难度

#### 5.1.2 几何约束缺失
- 旋转矩阵的正交性约束难以保证
- 齐次坐标的第四行固定为[0, 0, 0, 1]约束未利用
- 尺度信息在矩阵中混合，难以独立优化

### 5.2 矩阵分解优化策略

#### 5.2.1 分解原理
SfM模式将ST：

```
STransransG分解为G = STransW @ WTransG * scaleWtG
```

其中：
- **STransW**：可优化的世界变换矩阵
- **WTransG**：来自SfM的固定变换矩阵
- **scaleWtG**：独立优化的缩放因子

#### 5.2.2 参数降维
- **传统方法**：16个优化参数
- **SfM方法**：3个优化参数（scaleWtG + 2个平移参数）
- **降维比例**：16 → 3，减少81.25%的参数

### 5.3 优化算法实现

#### 5.3.1 优化变量
```python
def _fitSTransG_sfm(self, points_3d, points_2d):
    """SfM模式优化实现"""
    
    # 1. 参数初始化
    center_x = 0.5  # 屏幕中心x坐标（归一化）
    center_y = 0.5  # 屏幕中心y坐标（归一化）
    scale_wtg = 1.0  # 初始缩放因子
    
    initial_params = [center_x, center_y, scale_wtg]
    
    # 2. 定义残差函数
    def residual_function(params):
        center_x, center_y, scale_wtg = params
        
        # 构建STransW矩阵
        STransW = np.array([
            [1, 0, center_x],
            [0, 1, center_y],
            [0, 0,     1   ],
            [0, 0,     0   ]
        ])
        
        # 计算STransG
        STransG = STransW @ self.wtransg * scale_wtg
        
        # 投影计算
        projected = self.project_3d_to_2d(points_3d, STransG)
        
        return points_2d - projected
    
    # 3. 非线性最小二乘优化
    result = opt.least_squares(residual_function, initial_params)
    
    return result
```

#### 5.3.2 约束处理
```python
def apply_constraints(params):
    """应用参数约束"""
    center_x, center_y, scale_wtg = params
    
    # 屏幕坐标约束
    center_x = np.clip(center_x, 0.0, 1.0)
    center_y = np.clip(center_y, 0.0, 1.0)
    
    # 缩放因子约束
    scale_wtg = np.clip(scale_wtg, 0.1, 10.0)
    
    return [center_x, center_y, scale_wtg]
```

### 5.4 数值稳定性分析

#### 5.4.1 矩阵条件数
- **传统方法**：4×4矩阵条件数通常较大
- **SfM方法**：分解后的矩阵具有良好的数值特性
- **优势**：减少舍入误差，提高优化收敛性

#### 5.4.2 梯度计算
```python
def compute_jacobian(params, residual_func):
    """计算雅可比矩阵"""
    epsilon = 1e-8
    n_params = len(params)
    n_residuals = len(residual_func(params))
    jacobian = np.zeros((n_residuals, n_params))
    
    for i in range(n_params):
        params_plus = params.copy()
        params_plus[i] += epsilon
        params_minus = params.copy()
        params_minus[i] -= epsilon
        
        residual_plus = residual_func(params_plus)
        residual_minus = residual_func(params_minus)
        
        jacobian[:, i] = (residual_plus - residual_minus) / (2 * epsilon)
    
    return jacobian
```

#### 6.2.1 相对坐标系统

```python
class CoordinateSystem:
    """坐标系统管理器"""
    
    @staticmethod
    def screen_to_relative(screen_x, screen_y, monitor_info):
        """屏幕坐标转相对坐标"""
        rel_x = (screen_x - monitor_info['x_offset']) / monitor_info['width']
        rel_y = (screen_y - monitor_info['y_offset']) / monitor_info['height']
        return rel_x, rel_y
    
    @staticmethod
    def relative_to_screen(rel_x, rel_y, monitor_info):
        """相对坐标转屏幕坐标"""
        screen_x = monitor_info['x_offset'] + rel_x * monitor_info['width']
        screen_y = monitor_info['y_offset'] + rel_y * monitor_info['height']
        return screen_x, screen_y
```

```python
def auto_select_best_monitor(gaze_point, monitors, calibration_data):
    """基于注视点位置智能选择屏幕"""
    
    # 1. 转换注视点到全局坐标
    gaze_global_x = gaze_point[0]
    gaze_global_y = gaze_point[1]
    
    # 2. 判断注视点是否在显示器范围内
    for monitor in monitors:
        bounds = get_screen_bounds(monitor['index'])
        if (bounds['x_min'] <= gaze_global_x <= bounds['x_max'] and 
            bounds['y_min'] <= gaze_global_y <= bounds['y_max']):

                return monitor['index']
    
    # 4. 默认返回主屏幕
    return 0
```

- **校准条件**：该显示器是否有对应的校准数据
- **优先级条件**：主屏幕（index=0）优先级更高

```python
def calculate_gaze_mouse_distance(gaze_point, mouse_position):
    """计算视线与鼠标位置的距离"""
    distance = np.sqrt((gaze_point[0] - mouse_position[0])**2 + 
                      (gaze_point[1] - mouse_position[1])**2)
    return distance

def is_distance_within_threshold(distance, monitor_count):
    """判断距离是否在阈值内"""
    base_threshold = 50  # 像素
    adaptive_threshold = base_threshold * (1 + monitor_count * 0.5)
    return distance <= adaptive_threshold
```

```python
class AdaptiveSmoothingFilter:
    """自适应平滑滤波器"""
    
    def __init__(self, initial_alpha=0.3):
        self.alpha = initial_alpha
        self.filtered_point = None
        self.confidence_threshold = 0.7
        
    def update(self, raw_gaze_point, confidence):
        """更新注视点"""
        
        # 置信度检查
        if confidence < self.confidence_threshold:
            return self.filtered_point
        
        # 稳定性评估
        if self.filtered_point is None:
            self.filtered_point = raw_gaze_point
            return self.filtered_point
        
        # 动态调整平滑参数
        movement_magnitude = np.linalg.norm(np.array(raw_gaze_point) - np.array(self.filtered_point))
        
        if movement_magnitude > 20:  # 大幅移动时减少平滑
            self.alpha = min(0.8, self.alpha * 1.2)
        else:  # 稳定时增加平滑
            self.alpha = max(0.1, self.alpha * 0.9)
        
        # 应用平滑
        smoothed_x = (1 - self.alpha) * self.filtered_point[0] + self.alpha * raw_gaze_point[0]
        smoothed_y = (1 - self.alpha) * self.filtered_point[1] + self.alpha * raw_gaze_point[1]
        
        self.filtered_point = (smoothed_x, smoothed_y)
        return self.filtered_point
```

```python
def auto_move_mouse(target_position, current_mouse_position):
    """自动移动鼠标到目标位置"""
    
    # 1. 计算移动向量
    move_vector = np.array(target_position) - np.array(current_mouse_position)
    distance = np.linalg.norm(move_vector)
    
    # 2. 分步移动以避免突然跳跃
    if distance > 10:  # 如果距离较远，分步移动
        step_size = min(distance * 0.3, 50)  # 每步最大50像素
        step_vector = move_vector / distance * step_size
        new_position = np.array(current_mouse_position) + step_vector
        
        # 调用鼠标移动API
        win32api.SetCursorPos((int(new_position[0]), int(new_position[1])))
        
        return False  # 未完成移动
    else:
        # 到达目标位置
        win32api.SetCursorPos((int(target_position[0]), int(target_position[1])))
        return True   # 移动完成
```

```python
        for key in keys[:-1]:
            if key not in config:

            config = config[key]

        config[keys[-1]] = value
        
        # 触发回调
        self.trigger_callback(key_path, value)

                json.dump(self.config, f, indent=2, ensure_ascii=False)
        except Exception as e:
            print(f"保存配置失败: {e}")
    
    def subscribe(self, key_path, callback):

        if key_path not in self.callbacks:
            self.callbacks[key_path] = []
        self.callbacks[key_path].append(callback)

        """触发配置变化回调"""
        if key_path in self.callbacks:
            for callback in self.callbacks[key_path]:
```

```python
import torch
import torch.nn as nn

class GazeEstimationNet(nn.Module):
    """注视点估计网络"""
    
    def __init__(self):
        super().__init__()
        self.backbone = self.build_backbone()
        self.regressor = nn.Sequential(
            nn.Linear(512, 256),
            nn.ReLU(),
            nn.Linear(256, 2)  # x, y坐标
        )
        self.confidence_estimator = nn.Sequential(
            nn.Linear(512, 128),
            nn.ReLU(),
            nn.Linear(128, 1),
            nn.Sigmoid()
        )
    
    def forward(self, x):
        features = self.backbone(x)
        gaze_coords = self.regressor(features)
        confidence = self.confidence_estimator(features)
        return gaze_coords, confidence
    
    def build_backbone(self):
        """构建骨干网络"""
        return nn.Sequential(
            nn.Conv2d(3, 64, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),
            # ... 更多层
        )

class GazeTrackingSystem:

    def __init__(self, model_path: str):
        self.device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
        self.model = GazeEstimationNet().to(self.device)
        self.load_weights(model_path)
        self.model.eval()
        
    def load_weights(self, model_path: str):
        """加载模型权重"""
        checkpoint = torch.load(model_path, map_location=self.device)
        self.model.load_state_dict(checkpoint['model_state_dict'])
        
    def predict(self, frame: np.ndarray) -> GazePoint:
        """预测注视点"""
        with torch.no_grad():
            # 预处理
            tensor = self.preprocess_frame(frame)
            
            # 推理

            # 后处理
            x, y = gaze_coords.cpu().numpy()[0]
            conf = confidence.cpu().numpy()[0][0]
            
            return GazePoint(x=x, y=y, confidence=conf)
```

```python
class EventManager:
    """事件管理器"""
    
    def __init__(self):
        self.event_handlers = {}
        self.event_queue = []
        
    def register_handler(self, event_type: str, handler: callable):
        """注册事件处理器"""
        if event_type not in self.event_handlers:
            self.event_handlers[event_type] = []
        self.event_handlers[event_type].append(handler)
    
    def emit_event(self, event_type: str, data: dict):
        """发射事件"""
        event = {
            'type': event_type,
            'data': data,
            'timestamp': time.time()
        }
        self.event_queue.append(event)
    
    def process_events(self):
        """处理事件队列"""
        while self.event_queue:
            event = self.event_queue.pop(0)
            self.handle_event(event)
    
    def handle_event(self, event: dict):
        """处理单个事件"""
        event_type = event['type']
        if event_type in self.event_handlers:
            for handler in self.event_handlers[event_type]:
                try:
                    handler(event['data'])
                except Exception as e:
                    print(f"事件处理器错误 {event_type}: {e}")
```
