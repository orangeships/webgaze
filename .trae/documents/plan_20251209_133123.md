# 架构重构计划

## 1. 重构目标
将 `eye_hand_interaction_click_base.py` 文件按照功能逻辑分离到不同的类和模块中，提高代码的可维护性和可读性，同时保持所有原有功能和接口不变。

## 2. 现有代码结构分析
当前文件包含以下主要功能模块：
- UI相关类（TransparentWindow, EyeHandInteractionUI, InteractionOverlay, FadeOutCircle）
- 核心系统类（EyeHandInteractionSystem）
- 滤波和分析类（LightweightKalmanFilter, GazeDispersionAnalyzer）
- 交互逻辑（校准、注视跟踪、手眼协调、屏幕切换）

## 3. 重构方案

### 3.1 模块划分
创建以下模块文件：
- `ui_components.py`：UI相关类
- `core_system.py`：核心系统类
- `gaze_analysis.py`：注视点分析和滤波
- `hand_eye_coordination.py`：手眼协调逻辑
- `screen_management.py`：屏幕管理和切换
- `main.py`：主入口函数

### 3.2 类划分

| 模块名称 | 包含类 | 主要功能 |
|---------|-------|---------|
| ui_components.py | TransparentWindow, EyeHandInteractionUI, InteractionOverlay, FadeOutCircle | 处理UI显示、交互界面、动画效果 |
| core_system.py | EyeHandInteractionSystem | 系统核心逻辑，协调各模块 |
| gaze_analysis.py | LightweightKalmanFilter, GazeDispersionAnalyzer | 注视点平滑、离散度分析 |
| hand_eye_coordination.py | (新类) HandEyeCoordinator | 处理手眼协调机制、鼠标自动移动 |
| screen_management.py | (新类) ScreenManager | 处理多屏检测、切换、校准数据管理 |

### 3.3 依赖关系
```
main.py → core_system.py → [ui_components.py, gaze_analysis.py, hand_eye_coordination.py, screen_management.py]
```

## 4. 重构步骤

1. 创建新的模块文件
2. 将现有类移动到相应模块
3. 提取新类来处理特定功能
4. 更新导入和依赖关系
5. 创建main.py作为入口点
6. 测试所有功能是否正常工作

## 5. 关键注意事项

- 保持所有原有方法的名称、参数和返回值不变
- 确保跨模块的依赖关系正确
- 维持原有的单例模式和状态管理
- 确保校准数据的正确加载和保存
- 保持与原有UI交互的一致性

## 6. 预期效果

- 代码结构更清晰，功能模块划分明确
- 便于后续扩展和维护
- 提高代码可读性
- 保持所有原有功能正常工作
