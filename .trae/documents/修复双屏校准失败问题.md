## 问题分析

**错误信息**：`ValueError: Length mismatch: Expected axis has 0 elements, new values have 39 elements`

**根本原因**：screen_management.py在调用`calibrate`方法时，**没有传递`display_index`参数**，导致：
1. 所有显示器的校准界面都显示在**第一个显示器**上
2. 用户无法在其他显示器上看到校准点，无法正确注视
3. `can_record`条件始终不满足，没有记录任何校准数据
4. 最终`self.df`为空，设置columns时失败

## 修复方案

### 1. 修复screen_management.py中的calibrate调用

**问题**：在`perform_dual_screen_calibration`方法中，调用`calibrate`时没有传递`display_index`参数

**修复**：将显示器索引`i`作为`display_index`参数传递给`calibrate`方法

**代码修改**：
```python
# 错误的调用（screen_management.py第437行）
STransG = current_homtrans.calibrate(model, cap, sfm=True, filename=calibration_filename)

# 正确的调用（添加display_index参数）
STransG = current_homtrans.calibrate(model, cap, sfm=True, display_index=i, filename=calibration_filename)
```

### 2. 确保每个显示器使用正确的校准界面

**效果**：
- 第一个显示器校准：校准界面显示在显示器0
- 第二个显示器校准：校准界面显示在显示器1
- 用户能在对应显示器上看到校准点，正确注视
- `can_record`条件满足，记录校准数据
- `self.df`不为空，设置columns成功
