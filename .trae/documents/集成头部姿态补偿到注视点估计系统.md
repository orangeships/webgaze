# 集成头部姿态补偿到注视点估计系统

## 1. 实现目标

将头部姿态补偿集成到现有的注视点估计系统中，提高注视点估计的准确性，特别是在用户头部移动时。

## 2. 核心思路

* 当用户头部移动时，原始注视向量是相对于头部坐标系的

* 需要将注视向量转换为相对于相机坐标系的向量

* 使用头部旋转矩阵的逆矩阵对注视向量进行补偿

## 3. 实现步骤

### 3.1 集成头部姿态估计功能

* 将 `head_pose_estimation.py` 中的 `HeadPoseEstimator` 类集成到 `simple_gaze_tracker.py` 中

* 在 `EyeHandInteractionSystem.initialize()` 方法中初始化头部姿态估计器

### 3.2 修改 `_getGazeOnScreen` 函数

* 修改 `homtransform.py` 中的 `_getGazeOnScreen` 函数，添加 `rmat` 参数用于接收头部旋转矩阵

* 在函数内部使用头部旋转矩阵对注视向量进行补偿

### 3.3 更新调用关系

* 在 `simple_gaze_tracker.py` 中获取头部姿态数据

* 将头部旋转矩阵传递给 `_getGazeOnScreen` 函数

### 3.4 坐标系统转换

* 确保头部旋转矩阵和注视向量在同一个坐标系统中

* 必要时对旋转矩阵进行调整

## 4. 代码修改详情

### 4.1 `simple_gaze_tracker.py` 修改

* 导入 `HeadPoseEstimator` 类

* 在 `EyeHandInteractionSystem.__init__()` 中添加头部姿态估计器初始化

* 在 `EyeHandInteractionSystem.initialize()` 中初始化头部姿态估计器

* 在 `run_interaction_mode()` 中获取头部姿态数据

* 将头部旋转矩阵传递给 `_getGazeOnScreen` 函数

### 4.2 `homtransform.py` 修改

* 修改 `_getGazeOnScreen` 函数签名，添加 `rmat` 参数

* 在函数内部添加头部姿态补偿逻辑：

  ```python
  # 应用头部姿态补偿
  if rmat is not None:
      # 将注视向量从头部坐标系转换到相机坐标系
      gaze = rmat @ gaze
  ```

### 4.3 坐标系统调整

* 检查头部旋转矩阵和注视向量的坐标系统是否一致

* 必要时对旋转矩阵进行调整，确保补偿正确

## 5. 注意事项

### 5.1 坐标系统一致性

* 确保头部旋转矩阵和注视向量在同一个坐标系统中

* 检查 MediaPipe 头部姿态估计的坐标系统定义

* 确保旋转矩阵的方向正确

<br />

### 5.2 校准影响

* 头部姿态补偿可能需要重新校准

* 在校准时考虑头部姿态变化

* 确保校准数据包含不同头部姿态下的数据

### 5.3 调试和测试

* 添加调试输出，查看补偿前后的注视向量变化

* 测试不同头部姿态下的注视点估计准确性

* 调整头部姿态补偿的参数，优化性能和准确性

## 6. 预期效果

* 当用户头部移动时，注视点估计更加准确

* 提高系统的鲁棒性，适应不同用户的头部运动习惯

* 降低对用户保持固定头部姿势的要求
