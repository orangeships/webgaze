# 重构注视系统代码计划

## 目标
将 `eye_hand_interaction_click_base.py` 重构为5个独立模块，保持原有功能不变，优化代码结构和性能。

## 模块划分

### 1. `ui_manager.py`
- **职责**：透明覆盖层 + UI 页面流程
- **包含类**：
  - `TransparentWindow` - 透明窗口基类
  - `EyeHandInteractionUI` - 主UI管理器
  - `InteractionOverlay` - 交互区域覆盖层
  - `FadeOutCircle` - 渐变消失圆圈动画
- **优化点**：
  - 统一抽象UI widget创建函数为模板
  - 将透明窗、渐变圈、事件过滤器拆分为独立类
  - 简化UI创建流程，减少重复代码

### 2. `screen_manager.py`
- **职责**：所有与多屏有关的逻辑
- **核心功能**：
  - 显示器检测与信息管理
  - 屏幕切换与校准数据加载
  - 绝对坐标 ↔ 相对坐标转换
  - 跨屏距离计算
  - 边界缓冲与自动切屏状态管理
- **包含方法**：
  - `_detect_monitors`
  - `get_target_screen`
  - `switch_to_monitor_with_coordinate_update`
  - 坐标转换相关方法

### 3. `calibration_manager.py`
- **职责**：校准流程统一管理
- **核心功能**：
  - 单屏校准
  - 双屏校准
  - 校准数据保存与加载
  - 根据显示器索引管理校准结果
- **优化点**：
  - 将分散的校准逻辑集中管理
  - 简化校准流程
  - 优化校准数据存储结构

### 4. `gaze_processor.py`
- **职责**：注视点处理与分析
- **核心功能**：
  - Gaze的SfM映射流程
  - 自适应平滑算法
  - 注视点离散度分析
  - 手眼协同交互处理
- **包含类**：
  - `GazeDispersionAnalyzer` - 注视点离散度分析器
- **优化点**：
  - 统一平滑算法，消除重复实现
  - 优化SfM映射流程
  - 简化手眼交互逻辑

### 5. `main.py`
- **职责**：系统主流程与摄像头循环
- **核心功能**：
  - 系统初始化
  - 摄像头管理
  - 主交互循环
  - 各模块协调

## 重构步骤

1. 创建 `eye_hand_system` 目录结构
2. 编写每个模块的基础框架
3. 逐步迁移代码，确保功能不变
4. 优化各模块内部实现
5. 测试整体功能，确保无问题

## 注意事项

- 保持原有功能不变，特别是单屏/多屏校准、鼠标右键跳转等核心功能
- 优化代码结构，减少重复和冗余
- 提高代码可读性和可维护性
- 确保各模块之间的依赖关系清晰
- 不引入新的外部依赖

## 预期成果

- 代码结构清晰，模块化程度高
- 各模块职责明确，便于维护和扩展
- 性能优化，减少重复计算
- 可读性提高，便于后续开发
