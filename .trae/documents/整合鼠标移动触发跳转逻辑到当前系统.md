# 整合鼠标移动触发跳转逻辑方案

## 1. 分析与理解

### 1.1 当前系统结构
- `core_system.py`: 主系统协调类，管理所有子模块
- `hand_eye_coordination.py`: 手眼协调器，负责鼠标自动移动
- `ui_components.py`: UI组件和动画效果
- `eye_hand_interaction_p_base.py`: 包含鼠标移动触发跳转逻辑的原始文件

### 1.2 鼠标移动触发跳转逻辑核心
- **滑动窗口机制**: 收集最近8个注视点，使用MAD（中位数绝对偏差）检测凝视稳定性
- **鼠标移动检测**: 收集最近5个鼠标位置，计算移动距离和方向
- **方向匹配**: 使用余弦相似度判断鼠标移动方向与凝视方向是否一致
- **传送冷却**: 1秒冷却时间，防止频繁触发
- **视觉反馈**: 绿色渐变圆圈动画

### 1.3 现有手眼协调机制
- 基于鼠标右键触发
- 简单的dwell检测（3帧注视点稳定性）
- 自动移动到注视点

## 2. 整合方案

### 2.1 整合目标
- **模块位置**: `hand_eye_coordination.py` - HandEyeCoordinator类
- **整合策略**: 保留现有鼠标右键触发机制，新增鼠标移动触发机制，两者并行工作
- **核心原则**: 保持现有方法签名不变，兼容多屏环境

### 2.2 具体修改点

#### 2.2.1 属性初始化
在`__init__`方法中添加：

```python
# 滑动窗口机制相关
self.sliding_window_gaze_points = deque(maxlen=8)  # 滑动窗口，最多8个注视点
```

#### 2.2.2 新增方法
1. `_check_sliding_window_distribution`: 滑动窗口凝视稳定性分析
2. `_check_mouse_movement_and_trigger_cursor`: 鼠标移动检测和触发条件判断
3. `_calculate_cosine_similarity_to_gaze`: 计算鼠标移动方向与凝视方向的余弦相似度
4. `_calculate_distance_change`: 计算鼠标与注视点距离变化
5. `_combined_direction_check`: 综合方向判断
6. `_calculate_circular_teleport`: 计算圆周传送目标点
7. `_trigger_fade_circle_cursor_move_and_reset`: 触发传送和视觉反馈

#### 2.2.3 整合到现有流程
在`_process_hand_eye_coordination`方法中添加：

```python
self._process_mouse_movement_triggered_teleport(gaze_point)
```

#### 2.2.4 新增主处理方法
```python
def _process_mouse_movement_triggered_teleport(self, gaze_point):
    """处理鼠标移动触发的传送逻辑"""
    # 持续收集注视点到滑动窗口
    self.sliding_window_gaze_points.append((time.time() * 1000, gaze_point[0], gaze_point[1]))
    
    # 当滑动窗口收集满8个点时进行检查
    if len(self.sliding_window_gaze_points) >= 8:
        self._check_sliding_window_distribution()
```

- **并行工作**: 新逻辑与现有鼠标右键触发机制并行运行，互不干扰

## 5. 风险与对策

- **性能风险**: 滑动窗口分析和方向计算可能增加CPU负担
  - 对策：优化算法，减少不必要的计算
- **误触发风险**: 可能在不需要时触发传送
  - 对策：严格的触发条件，包括滑动窗口稳定性、鼠标移动距离和方向匹配
- **多屏兼容风险**: 可能在多屏环境下出现坐标计算错误
  - 对策：利用现有成熟的屏幕管理机制
